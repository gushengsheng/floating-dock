# Floating Dock — 悬浮图标任务栏 + 快捷文件夹

一个替代 Windows 任务栏的悬浮胶囊：**常驻置顶、只有图标、没有开始按钮和时间**，
可以用快捷键随时收起来，也可以一键在「它」和「系统任务栏」之间切换。
左上角还有一个按钮，点开就是**快捷文件夹模式**（多窗口文件管理，纯键盘操作）。

因为系统任务栏已经被自动隐藏，这个悬浮栏就是你日常的窗口切换入口。

## 悬浮栏

- 悬浮圆角胶囊，贴屏幕底部居中，**始终置顶**，不占系统任务栏位置
- 只有图标：固定应用 + 正在运行的应用，没有开始菜单、没有时钟
- 点图标 = 切换窗口；当前窗口再点一次 = 最小化
- 右键图标：切换/最小化/关闭/固定；右键空白处：设置菜单
- 拖动胶囊可以换位置，松手自动吸附（靠近底部/居中），位置会被记住
- 开机自动启动（可在菜单里关掉）

> **简洁模式**（默认已开启）：底部不再有那排图标，改成左上角竖着的一列 ——
> 文件夹按钮 → 搜索胶囊 → 窗口切换的竖点（点在最下面）。
> 想恢复底部图标栏：右键胶囊 → 取消勾选「简洁模式」，或到设置里打开。

## 快捷文件夹模式

左上角那个文件夹按钮（或快捷键）打开一个全屏面板，里面可以并排放好几个「窗口」，
每个窗口是一个文件夹，文件以列表形式显示。

- **双击任何窗口**就进入那个窗口（高亮框进去），再用键盘在里面挑
- 文件列表：文件夹在前、文件在后，右侧显示文件大小
- **退出再进来，每个窗口还停在原来的那一层**（连同选中项一起记着）
- 窗口右上角「…」：更换文件夹 / 编辑标题 / 添加窗口 / 移除此窗口
- 右上角「＋ 添加窗口」：再开一个文件夹窗口（最多 6 个，自动排版）

### 键盘操作

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` 或 `W` `S` | 上下移动高亮框 |
| `←` `→` 或 `A` `D` | 在窗口之间左右切换（只有一个窗口时：`←` 上一级、`→` 进入文件夹） |
| `Enter` | 打开文件（用默认程序）/ 进入文件夹 |
| `Backspace` | 回到上一级 |
| `Tab` | 切换到下一个窗口 |
| `Ctrl` + `N` | **新建**：带后缀就是文件（`a.txt`），不带后缀就是文件夹（`报告`） |
| `Ctrl` + `Shift` + `N` | 新建文件夹（不管有没有后缀，强制建文件夹） |
| `F2` | **重命名**选中的文件/文件夹 |
| `Delete` | **删除**选中的项（移到回收站，会先确认一次） |
| `Esc` | 退出快捷文件夹模式 |

鼠标也行：单击选中、双击打开、滚轮滚动。

## 多窗口切换器

左上角文件夹按钮下面有一列竖直的小圆点，点数是当前打开的窗口数（最多显示 8 个）。

- **点一下这列点**，或者按 `Ctrl` + `Alt` + `W`：屏幕其余部分变黑，左边弹出窗口列表
- `↑` `↓`（或 `W` `S`）选择，`Enter` 或鼠标点一下就切过去，`Esc` 关掉
- 切过去的同时会把那个窗口**提到最前面**（不只是抢焦点），最小化的会先还原
- 列表按 z 序排，最上面的就是当前窗口；打开时默认选中第二个（相当于 Alt+Tab）
- 右键这列点：打开切换器 / 设置… / 隐藏这列点（可在设置里重新打开）

## 设置

三个入口都能打开：

- 悬浮栏右键菜单 → **设置…**
- 左上角文件夹按钮右键菜单 → **设置…**
- 左侧圆点右键 → **设置…**
- 或者命令行 `FloatingDock.exe --settings` 直接打开

能改的东西：

| 项目 | 说明 |
| --- | --- |
| 快捷文件夹 | 打开快捷文件夹的快捷键 |
| 窗口切换器 | 打开这个切换器的快捷键 |
| 悬浮栏显示/隐藏 | 收起/唤出底部悬浮栏 |
| 系统任务栏切换 | 自动隐藏 ↔ 常驻显示 |
| 开机自动启动 | 写 `HKCU\...\Run` |
| 全屏应用时自动隐藏悬浮栏 | 看视频/玩游戏时让位 |
| 显示左上角文件夹按钮 / 显示左侧窗口切换点 | 不想要就关掉 |
| 图标大小 | 24 / 28 / 32 / 36 / 40 px |

快捷键格式：`Ctrl` / `Alt` / `Shift` / `Win` 用 `+` 连接，键可以是 `A`~`Z`、`0`~`9`、`F1`~`F12`、
或 `Space` / `Tab` / `Enter` / `Esc` / `` ` `` / `-` / `[` / `]` / `;` / `'` / `,` / `.` / `/` 等。
必须至少带一个修饰键，且四个快捷键不能重复；保存时会检查。

## 目标文件夹搜索

悬浮栏最右边有一个放大镜图标（图标和它的分隔线之后），点它、或按 `Ctrl` + `Alt` + `S`，弹出搜索框。

- 右下角「目标文件夹」→ **＋ 添加文件夹…** 添加要搜索的文件夹，列表里点文件夹名即可移除
- 添加过的文件夹会存进 `config.json` 的 `SearchFolders`，下次启动还在
- 输入文件名的一部分就能搜（不区分大小写），前缀匹配排前面
- `↑` `↓` 选择，`Enter` 或点一下用默认程序打开，`Esc` 关闭
- 首次打开会在后台扫描，底部显示「N 个文件夹 · M 个文件」；改动文件夹后会重新扫描
- 上限 12 万个文件（超出会显示「已达上限」），跳过隐藏/系统目录和 junction

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Win` + `` ` `` | 显示 / 隐藏全部悬浮图标（胶囊 + 左上角按钮 + 竖点） |
| `Ctrl` + `Alt` + `B` | 系统任务栏：自动隐藏 ↔ 常驻显示 之间切换 |
| `Ctrl` + `Alt` + `F` | 打开快捷文件夹（被占用时会自动换一个并弹提示） |
| `Ctrl` + `Alt` + `W` | 打开多窗口切换器 |
| `Ctrl` + `Alt` + `S` | 打开目标文件夹搜索 |

被别的软件占用时会自动换一个可用的组合（并弹提示）；也可以在设置或配置文件里改。
菜单里显示的是**实际生效**的组合。

## 怎么用

- 想加应用：右键悬浮栏空白处 → **添加应用…**
- 固定正在运行的应用：右键它的图标 → **固定到悬浮栏**
- 临时再开一个窗口：`Shift` + 点图标
- 图标太多时：鼠标滚轮可以横向滚动
- 不想要左上角按钮：右键它 → 隐藏，或在悬浮栏右键菜单里重新打开

## 配置文件

`%APPDATA%\FloatingDock\config.json`

```json
{
  "Pinned": ["C:\\Windows\\explorer.exe"],
  "DockHotkey": "Win+`",
  "TaskbarHotkey": "Ctrl+Alt+B",
  "FolderHotkey": "Ctrl+Alt+F",
  "SwitcherHotkey": "Ctrl+Alt+W",
  "HideInFullscreen": false,
  "IconSize": 28,
  "AutoStart": true,
  "HideCornerButton": false,
  "HideSwitcherDots": false
}
```

`%APPDATA%\FloatingDock\folders.json` 存快捷文件夹的窗口列表、每个窗口的路径和选中项：

```json
{
  "Panes": [
    { "Title": "桌面", "Path": "C:\\Users\\you\\Desktop", "Selected": 3 },
    { "Title": "下载", "Path": "C:\\Users\\you\\Downloads" }
  ],
  "ActiveIndex": 0
}
```

- `HideInFullscreen`：全屏应用（播放器、游戏）时自动让位，改 `true` 即可
- `IconSize`：图标像素，24 / 28 / 32 / 36 / 40
- 改完右键悬浮栏 → **重新加载配置**

日志：`%APPDATA%\FloatingDock\dock.log`（只在出错时才有内容）

## 开机自启

菜单里的「开机自动启动」开关即可，对应注册表：
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `FloatingDock` 值。
不需要时菜单里取消勾选，或直接删这个值。

## 自己重新编译

不需要装 .NET SDK，用 Windows 自带的 .NET Framework 编译器：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1        # 只编译
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Run   # 编译并启动
```

产物：`dist\FloatingDock.exe`（x64，约 115 KB）。源码在 `src\`：

| 文件 | 作用 |
| --- | --- |
| `Native.cs` | Win32 P/Invoke（窗口枚举、激活、热键、任务栏状态、回收站删除） |
| `Tracker.cs` | 运行中窗口的枚举与分组 |
| `DockWindow.cs` | 悬浮栏本体（也负责热键和各个窗口的显示/隐藏） |
| `CornerButton.cs` | 左上角文件夹按钮 |
| `SwitcherDots.cs` | 左侧那列窗口切换圆点 |
| `WindowSwitcher.cs` | 展开的窗口切换器 |
| `SearchIndex.cs` | 目标文件夹的文件索引（后台扫描 + 查询） |
| `SearchPanel.cs` | 目标文件夹搜索面板 |
| `SettingsWindow.cs` | 设置界面 |
| `FolderOverlay.cs` | 快捷文件夹面板 |
| `FolderSettings.cs` | 面板窗口状态的读写 |
| `TextPrompt.cs` | 新建/重命名用的输入框 |
| `ConfirmDialog.cs` | 删除确认框 |
| `Icons.cs` | 图标提取（shell 高清图标 + 扩展名图标） |
| `Config.cs` | 配置读写、热键解析、开机自启 |

`tools\` 里是几个调试用的小工具（截图 / 发送热键 / 模拟点击 / 窗口探测），和主程序无关。

## 已知限制

- 以管理员身份运行的窗口，普通权限的悬浮栏无法把它切到前台（Windows 的权限隔离），
  这种情况需要以管理员身份运行悬浮栏。
- UWP / 商店应用的图标取的是宿主进程的图标，个别会显示成通用图标。
- 快捷文件夹里不显示隐藏文件和系统文件；删除文件没有做（需要的话可以再加）。
